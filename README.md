## The entry

> The kettle clicks off a breath before the boil, as if it changed its mind about waking the house.

One sentence, 97 characters, on a small moment of wonder in everyday life: the pause before a kettle clicks, turned at an angle the reader has not met — the kettle deciding, for one breath, not to wake the house.

## How it works

`main.py` is a deterministic Python program. It writes the sentence above to `/output/entry.txt` (UTF-8, 97 characters, no trailing newline) and prints it. No input, no network, no randomness, no environment secrets.

Run it:

```sh
python3 main.py
```
